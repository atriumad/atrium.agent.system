# Five engines, *one machine*

Each engine has a question, a journey stage and a score. A service belongs to one engine only: the one whose score it moves. If it moves two, the earlier stage wins.

## Discoverability

| | |
| --- | --- |
| **Tagline** | Get found |
| **Question** | How well set up are you? Does the digital front door answer every question in under 10 seconds? |
| **Stages** | Stranger → Discovery |
| **North-star metric** | GBP actions: directions + calls + website clicks, 30 days |
| **Services** | Google Business Profile, Local SEO, Delivery Listings Admin |
| **Measured by** | GBP actions, discovery searches, direct searches, Maps rank, listings synced |
| **Practice rubric** | Profile completeness, NAP consistency, schema present, bio-link health |
| **Agent** | [Concierge](../agents/concierge) |

## Acquisition

| | |
| --- | --- |
| **Tagline** | Get seen |
| **Question** | How much of the city sees you? Do you make the mental shortlist before hunger strikes? |
| **Stages** | Stranger → Discovery |
| **North-star metric** | Impressions, 30 days (secondary: engagements, profile visits, intent actions) |
| **Services** | Content Production, Social Media Management, Meta Awareness Ads, Google Awareness Ads, Brand Ambassadors |
| **Measured by** | Impressions, reach, video views, followers, engagements, profile visits, sessions, link clicks, intent actions |
| **Practice rubric** | Posting consistency, feed cohesion, hook quality, geo-tag discipline |
| **Agent** | [Herald](../agents/herald) |

## Reputation

| | |
| --- | --- |
| **Tagline** | Get chosen |
| **Question** | Do they choose you when they compare? |
| **Stages** | Consideration → First Visit |
| **North-star metric** | Google rating against the 10-mile average, with review velocity |
| **Services** | Reviews + Rating Improvement (review generation, replies in 24–48 h, private recovery) |
| **Measured by** | Rating, new reviews, response rate, reply time, 5-star share, review-request conversion, survey score |
| **Practice rubric** | Reply speed, reply quality, review-ask cadence, sentiment handling |
| **Agent** | [Host](../agents/host) |

## Retention

| | |
| --- | --- |
| **Tagline** | Bring them back |
| **Question** | Do they come back, and how often? |
| **Stages** | First Visit → Loyal Regular |
| **North-star metric** | Repeat guest rate: guests with a repeat visit / guests |
| **Services** | CRM + Automations, Email Marketing, Loyalty & Rewards |
| **Measured by** | Repeat guest rate, loyalty members, open rate and click rate (later, with marketing and CRM), redemptions, win-back returns, email revenue, opt-outs |
| **Practice rubric** | List hygiene, automation coverage, offer cadence, segmentation depth |
| **Agent** | [Sommelier](../agents/sommelier) |

## Growth

| | |
| --- | --- |
| **Tagline** | Tracked revenue |
| **Question** | What are the ads and campaigns producing? Is every dollar traced to an order, booking or cover? |
| **Stages** | Consideration → Loyal Regular (the money end of every stage) |
| **North-star metric** | ROAS: sales / spend, by program, with cost per action |
| **Services** | Landing Pages, Campaign Content, Meta Performance, Google Performance, Event Marketing, Private Events, Catering Leads, Slow-Day Campaigns, Gift Cards, Grand Opening, Monthly Reports, 90-Day Roadmap |
| **Measured by** | Spend, paid impressions, clicks, orders and reservations from ads, matched on-premise orders, on-premise sales (estimated), ROAS, cost per action, leads |
| **Practice rubric** | Pixel health, creative refresh rate, budget pacing, landing-page match |
| **Agent** | [Steward](../agents/steward) |

## The loop

Discoverability makes the restaurant easy to find, Acquisition builds the mental shelf, Reputation turns research into a first visit, Retention turns a first visit into a habit, and Growth points the audience and the list at specific revenue goals. Loyal guests return reviews and referrals to the first three engines. No engine works in isolation: traffic is lost without reviews to convert it, and first visits are lost without Retention.

:::note Attribution and reporting are not engines
Attribution (which work earned which guest) and reporting (the story of the month) cut across all five engines. They live in the [Data](../data) layer and in the Growth services, and are delivered by [Maître](../agents/maitre).
:::
