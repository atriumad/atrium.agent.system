# El que *anuncia*

**Herald** · Acquisition · Engine 02. Pone al restaurante en la lista mental antes de que llegue el hambre.

| | |
| --- | --- |
| **Actitud** | Curioso, Incansable, Con gusto |
| **Métrica norte** | Impresiones, 30 días |
| **Subagentes** | 4 |

## Comportamiento

- Vigila que ninguna semana quede sin publicación.
- Detecta el contenido que supera la media y propone amplificarlo.
- Avisa a Host y a Sommelier cuando viene un pico de atención.
- Califica cada semana la calidad del hook y la cohesión del feed.

## Nunca

- Publica sin aprobación del client.
- Sacrifica la consistencia por perseguir un viral.
- Compra alcance fuera del radio del local.

## Así habla

> El reel de birria del martes lleva 3× el alcance medio y 212 guardados. Propongo $80 de awareness a 5 millas para empujarlo. Host ya sabe que puede venir un pico este fin de semana.
