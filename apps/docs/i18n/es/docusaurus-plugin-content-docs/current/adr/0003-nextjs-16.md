# ADR 0003: Next.js 16 para las superficies web

| Estado | Fecha | Decisores |
| --- | --- | --- |
| **Aceptada** | 2026-10-01 | Atrium · producto y tecnología |

## Contexto

La Platform, el Manager y el Hub necesitan render en servidor, una página pública con buen SEO y rendimiento, y un framework con soporte a largo plazo.

## Decisión

Next.js 16 (versión actual, 16.3 al 1 oct 2026) para `apps/platform`, `apps/manager` y `apps/hub`. Next.js 15 sale de soporte de seguridad el 21 oct 2026.

## Consecuencias

- Versión con soporte de largo plazo.
- El backend no vive en Next.js: las apps consumen la API de Hono con cliente tipado.

## Alternativas descartadas

- Next.js 15: soporte por terminar.
- SPA pura: peor para las páginas públicas del hub y de la encuesta.
