# ADR 0003: Next.js 16 for the web surfaces

| Status | Date | Deciders |
| --- | --- | --- |
| **Accepted** | 2026-10-01 | Atrium · product and technology |

## Context

The Platform, the Manager and the Hub need server rendering, a public page with good SEO and performance, and a framework with long-term support.

## Decision

Next.js 16 (current version, 16.3 as of 1 Oct 2026) for `apps/platform`, `apps/manager` and `apps/hub`. Next.js 15 leaves security support on 21 Oct 2026.

## Consequences

- Version with long-term support.
- The backend does not live in Next.js: the apps consume the Hono API through a typed client.

## Discarded alternatives

- Next.js 15: support about to end.
- Pure SPA: worse for the public hub and survey pages.
